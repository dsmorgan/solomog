# solomog help catalog — parsed by scripts/lib/help.sh (bash 3.2).
# Group membership is prefix-plus-map: a task's first colon-component (or the
# whole name if unprefixed) looks up `prefix`; new apps:foo / eks:bar land in
# the right group with no catalog edit. Unmapped tasks still appear under Other
# in `solomog help --all`.
#
# Lines (TAB-separated):
#   group   <name>  <index blurb>  <page title>
#   alias   <alias> <group>          extra help-topic names for a group
#   prefix  <key>   <group>          first-component (or whole name) → group
#   lead    <group> <task>           display first in that group (catalog order)
#   see     <group> <footer line>    extra line on the group page
#   ptitle  <prefix> <page title>    prefix-page heading (eks, vsphere, …)
